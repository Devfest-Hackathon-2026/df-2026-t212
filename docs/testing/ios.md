# MacでiOS版を試す方へ

今回は、After Hueを使った感想と、操作中に困ったところを教えてください。開発への参加をお願いするものではありません。

TestFlightでの配布はしていないため、Mac上のiPhone Simulatorで試す方法を案内しています。MacにはXcodeが必要です。セットアップと起動は、[READMEの依頼文](../../README.md#セットアップをllmに任せる)をLLMに渡して任せられます。READMEには、LLMが確認する環境、起動コマンド、困ったときに確認する箇所も書いてあります。

AIを使う場合は、ご本人のOpenAI APIキーを使ってください。AI用に他サービスのキーは必要ありません。LLMにローカルの設定ファイルを用意してもらい、キーの値だけ自分で入力できます。キーをチャットやGitHubへ貼る必要はありません。

起動したら、テスト用の写真を数枚取り込み、色を選んで保存し、開き直すところまで試してください。AutoやAskも使ってみて、次の操作が分かりにくかったところ、予想と違った動き、仕上がりの感想を教えてください。AIを使うと、写真の縮小版と編集依頼がOpenAIに送られます。

AskはSimulatorのソフトウェアキーボードを表示して試せると助かります。Macのキーボードだけでは、iPhoneで入力欄やSendが隠れる問題を確認できません。日本語の変換や、キーボードを閉じて再び入力する操作も確認したい点です。

Simulatorでは、実際のカメラや指での操作感は確かめられません。Macそのもののネイティブアプリを試すわけでもありません。この範囲で確認できないことは、そのまま未確認で構いません。

気づいたことはGitHubのIssueか普段の連絡手段で返してください。MacとSimulatorのOS、行った操作、実際に起きたことが分かれば十分です。可能ならスクリーンショットや短い録画を添えてください。原因の調査やコードの修正は必要ありません。
