# iPhoneで試す方へ

今回は、After Hueを使った感想と、操作中に困ったところを教えてください。開発への参加をお願いするものではありません。

カメラでの撮影も試していただきたいので、ご本人のMacから手元のiPhoneにアプリをインストールします。MacにはXcodeが必要です。ご本人の無料のAppleアカウントで署名できるため、有料のApple Developer Programへの登録は不要です。TestFlightでの配布はしていません。

セットアップと起動は、[READMEの依頼文](../../README.md#セットアップをllmに任せる)をLLMに渡して任せられます。READMEには、Macの環境確認、iPhoneの接続、無料署名、インストールまでの手順をまとめています。Appleアカウントへのログイン、iPhoneの信頼確認、デベロッパモードの有効化など、本人の操作が必要なところはLLMから案内してもらってください。

AIの秘密キーや課金アカウントを自分で用意する必要はありません。開発者から受け取ったCloud RunとFirebaseの公開接続設定を、READMEの手順でビルドに含めます。Firebaseの匿名認証を使うので、氏名やメールアドレスでの登録も不要です。

インストールしたらMacとの接続を外し、iPhoneのホーム画面からアプリを開いてみてください。まずカメラで撮影し、色を選んで保存し、開き直すところまで試してください。写真アプリからの取り込みやAuto、Askも使ってみて、次の操作が分かりにくかったところ、予想と違った動き、仕上がりの感想を教えてください。クラウドAIの初回利用前には送信内容の確認画面が出ます。承諾すると、写真の縮小版と編集依頼などがGoogle Cloudに送られます。自動現像をオンにすると、新しい写真が自動で送られることがあります。設定でクラウドAIをオフにでき、手動編集は引き続き使えます。最初はご自身で選んだ数枚のテスト写真で試せれば十分です。

アプリの表示は端末の言語にかかわらず英語です。Askへの依頼文は日本語でも入力できます。日本語を入力・変換したり、キーボードを閉じて再び入力したりしてみてください。写真を見ながら依頼を書けるか、入力欄やSendが隠れないかも確認したい点です。

無料署名は7日で期限が切れるため、その後も使う場合はMacから再ビルド・再インストールします。同じ設定で起動コマンドを再実行する手順はREADMEにあります。アプリを先に削除するとアプリ内のデータも失われるので、削除せずに更新してください。この期限は[Appleの無料アカウントの制限](https://developer.apple.com/help/account/basics/about-your-developer-account)によるものです。

気づいたことはGitHubのIssueか普段の連絡手段で返してください。iPhoneの機種とOS、行った操作、実際に起きたことが分かれば十分です。可能ならスクリーンショットや短い録画を添えてください。原因の調査やコードの修正は必要ありません。

AIはテスト期間中無料ですが、利用者ごととサービス全体に上限があります。一時的に使えなくなったら時間を置いて試し、解消しない場合は配布時の連絡先へお知らせください。自動で料金が請求されることはありません。詳しくはSettingsの「Terms of use」「Privacy」をご覧ください。
