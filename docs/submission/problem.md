# 取り組む課題

この文章は、開発者の体験と開発中のやり取りから整理した課題設定の案です。利用者調査によって普及度や効果を確認した主張とは区別します。

## 提出用の説明案

After Hueが取り組むのは、日常で心が動いたものを、自分の表現として残すまでにかかる編集の手間です。対象は、散歩や旅行、普段の暮らしで写真を撮り、気に入った一枚を自分なりに仕上げたい人です。

花の色や街角の看板に惹かれて撮っても、写真には周囲のものまで写ります。自分が何に惹かれたのかが伝わる形にするには、残す色や対象の範囲を選び、仕上がりを調整する作業が必要です。撮影した時の小さな発見を表現へつなげるには、撮影のしやすさに加えて、仕上げる段階の支援も必要だと考えました。

After Hueでは、写真に触れて残したい色を選べます。AIに最初の編集を任せたり、言葉で修正を頼んだりすることもできます。AIと人は同じ編集設定を扱うため、自動処理の後も、何を残すかを本人が調整できます。専門的な操作に慣れていなくても、自分の意図を試しながら写真を仕上げられることを目指しています。

仕上げた写真は、残した色や撮影場所から見返せます。タイトルや色のバッジを添えて印刷用画像にもでき、手帳に貼るなど、日常の中に置く使い方につながります。編集の手間を減らすだけでなく、撮った時の発見を、見返したり手元に残したりするところまでつなぐ設計です。

この取り組みの社会的な意義は、日常の体験を表現する機会を広げることにあると考えています。ただし、現時点では編集時間の短縮や、表現・振り返りの機会が増える効果を測定していません。まずは、利用者が自分の意図に合う仕上がりを作れるか、その写真を残したいと思えるかを確かめる必要があります。

## 課題と実装の対応

| 具体的な難しさ | 対応する設計 | 確認したいこと |
|---|---|---|
| 気に入った色を残すために、編集の操作を覚える必要がある | 写真上の採色、撮影時のプレビュー、Autoによる最初の編集 | 説明なしでも色を選び、意図した仕上がりに近づけられるか |
| 自動編集が本人の意図とずれた時、直し方が分からない | 人とAIで共通の編集設定、Keep／Exclude、範囲指定、Ask、Undo | 自動結果の一部分を本人が修正できるか |
| 写真が蓄積すると、以前気に入った一枚に戻る手がかりが少ない | 写真由来の色見本、色による絞り込み、地図と時期による振り返り | 残した色や場所を頼りに、見返したい写真へ戻れるか |
| 編集後、印刷して手元に残すために別の作業が要る | 同じ写真からタイトル・場所・日付・色バッジを添えて印刷用画像を作成 | 仕上がり全体を見ながら、残したい形に整えられるか |

## 主張の範囲

「写真が多い」こと自体を社会課題とはしません。焦点は、撮った写真を本人の意図に沿って仕上げ、残すまでの負担にあります。また、創造性の低下、SNSによる心理的な害、孤独の解消などは、今回確認した事実からは主張しません。

Exploreは、他の人の写真に出会い、自分の写真を公開するために開発中の機能です。現在の課題説明を支える実装済みの根拠には含めません。公開後に、写真との出会いが次の撮影や表現につながるかを別途検証します。
