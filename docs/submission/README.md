# After Hue 提出資料

After Hueは、写真の中で残したい色を選び、それ以外をモノクロにするアプリです。撮影や取り込みから、編集、色と地図による振り返り、印刷用画像の作成までをつなぎます。

初めて読む方は、[プロダクト説明](product.md)からご覧ください。[審査基準への応答](judging.md)には、各評価項目に関係する実装と、確認できる場所をまとめています。[技術構成](architecture.md)では、端末と外部サービスの役割を分けて説明しています。

この資料は提出前の作業版です。2026年11月10日時点でコードから確認した内容を記載し、これから作る機能は実装済みの説明に含めていません。Exploreは別ブランチ `feature/explore-gcp` で実装とローカルテストを進めています。GCPプロジェクト `after-hue-pdhaku0` は作成済みですが、課金アカウントの紐付けが上限により完了しておらず、サービスは未デプロイです。この版のGCP構成図は、実装中の構成を示しています。
