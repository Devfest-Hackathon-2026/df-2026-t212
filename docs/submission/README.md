# After Hue 提出資料

After Hueは、写真の中で残したい色を選び、それ以外をモノクロにするアプリです。撮影や取り込みから、編集、色と地図による振り返り、印刷用画像の作成までをつなぎます。

初めて読む方は、[プロダクト説明](product.md)からご覧ください。[審査基準への応答](judging.md)には、各評価項目に関係する実装と、確認できる場所をまとめています。[技術構成](architecture.md)では、端末と外部サービスの役割を分けて説明しています。

この資料は提出前の作業版です。2026年11月10日時点のコードと実接続確認に基づきます。Cloud Run、Firebase Authentication、Firestore、Vertex AIを使う編集エージェントを配置済みです。認証、写真の選別、現像、追加の編集依頼、端末側の描画まで実接続で確認しました。確認範囲は[実接続の記録](verification.md)にまとめています。Exploreは延期し、別ブランチの試作を今回の成果に含めていません。
